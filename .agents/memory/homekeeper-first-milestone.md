name: HomeKeeper first milestone
description: Product scope and guidance constraints for the first HomeKeeper release.
---

HomeKeeper is being built for a beginner developer working from an iPhone. Keep setup and test guidance simple and step by step. The first milestone is a local-only household asset tracker; do not add login, cloud sync, AI features, subscriptions, or payments. Help fix any preview or app errors before adding more features.

**Why:** the user explicitly set these scope and workflow requirements.

**How to apply:** prioritize stabilizing the existing Expo app and supporting iPhone testing before suggesting additional product work.
